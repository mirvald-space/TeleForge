# Changelog

## [1.0.0] - 2025-06-08

### Added
- Первая версия TeleForge - шаблон для Telegram ботов на aiogram 3.x
- Модульная архитектура с разделением ответственности
- Интеграция с MongoDB через асинхронный драйвер Motor
- Многоязычная поддержка (i18n) для английского, русского, украинского языков
- Система промежуточного ПО (middlewares) для обработки запросов
- Система команд с легкой регистрацией и обработкой
- Обработка ошибок и логирование
- SEO-оптимизированный README с многоязычной поддержкой
